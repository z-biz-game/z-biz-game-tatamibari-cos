# 畳バリ Tatamibari · 切块与墙的推理

在 `W×H` 的盘上，墙把格子切成若干块。记号写着它所在那一块的**形状**：`-` 要宽大于高、`|` 要高于宽、
`+` 要正方形；每一块恰好一个记号，每一块都得是长方形，而且任何一个格点上不许四块共角。这里出货的
每一盘都只有一个答案，也每一盘都能用七条局部推理（R1–R7）从空盘一路推到底——一次都不许靠猜。

本文里的数字只有两类来源：仓里读得到的代码（写成 `文件:行号`），和 2026-09-28 那一轮全绿跑出来的
读数。跑的命令是 `npm run check`、`npm test`（三套引擎断言 65 / 74 / 206 条，再加一条把本文自己的
行号读回来的 `tools/doctest.mjs`）、`SAMPLES=24 node
tools/balance.mjs`、`bash tools/verify.sh`，环境 Node v26.8.1 / macOS 26.6.2 / Apple M5 Pro
15 核。引擎断言与 `npm run check` 是当场重跑的（65 / 74 / 206 这三条读数 CI 的 ubuntu runner 上也是
同一组）；难度分位表取 06:09 那一跑（之前同代码还连跑过两次，只有墙钟列在动），浏览器门禁取 06:20
那两次跑（本机双形态与线上单形态各一跑），逐条列在下面。

**代码 > 本文档**：本文与 `js/`、`tools/` 冲突时，以代码和它跑出来的输出为准。

## 规则（玩家视角）

菜单里那五条就是规则本体（`index.html:31-35`），而且每一条都对得上引擎里的一个谓词
（`index.html:37-41` 把对应关系写在页面上）：

1. **`-` 的块宽 > 高**、**`|` 的块高 > 宽**、**`+` 的块是正方形**——记号字符与方向约束是
   `js/engine/counter.js` 的 `MARKER_CHAR` / `aspectOk`。
2. **每块恰好一个记号**，多一个少一个都算错。
3. **每一块都是长方形**，块与块之间用墙分开。
4. **任何一个格点上不能四块共角**（十字路口不许凑齐四家）——`js/engine/rules.js` 的
   `pointWindmill` / `windmillPoints`。

- 玩家画的不是格子，是**边**。每条内部边三态：未定 / 墙 / 同块（`js/engine/pencil.js:55`）。
  「同块」也是人能说出口的结论（"这格只能并进那块 `+` 的正方形"），所以两条通道都留着这一态。
- 判胜不另起口径：赢 = 边全定完 ∧ 每块确实是长方形 ∧ `invalidReason` 说这一盘合法
  （`js/ui/game.js:234`，它调 `js/engine/validate.js:40`）。而「什么算合法盘」在本仓**只有一份
  定义**，页面、生成器、三套测试台问的都是它——合法定义写第二遍，两个台架就会各自把 bug 写成期望
  （`js/engine/validate.js:14`、`tools/reference.mjs:3-9`）。

## 怎么玩

- 五档：入门 4×4、简单 4×5、中等 5×5、困难 5×6、大师 6×6（`js/engine/generate.js:299-320`）。
  **6×6 之上本轮出不起货**，理由与抽数写在 `js/engine/generate.js:329-345` 的 `UNSHIPPABLE` 里，
  `npm run balance` 每轮重新量一遍并打印数字。
- 也可以指定 seed（同一个 seed 同一张盘），或按日课开「全世界同一盘」：日课的 seed 串是
  `daily:<本地日期>:<档>`（`js/main.js:265`、日期键在 `js/main.js:131-136`，用本地日期不套 UTC）。
  「换一局」那颗按钮**不是**日期函数（`js/main.js:140-141` 用 `Date.now()` 与 `Math.random()`
  现造 seed）——界面不许在你说"换一局"的时候其实给你端回今天那盘。
- 落子：点一下一条边界，按住拖是一笔连画，从自己已经画下的线上起笔就是擦掉；`1` 画墙、`2` 打通、
  `3` 擦、`H` 提示、`G` 补一眼墙（免费）、`Z` 撤销、`N` 换一局（`index.html:155-156`）。
  一笔算一条撤销记录，不是每条边一条。
- 暂停：`P` / `空格` / 「暂停」那颗钮走的是同一个入口，冻住的是**两样东西**——侧栏那行用时，以及
  **整个盘面**。暂停期间点边、拖一笔、`1` `2` `3` `m` `h` `g` `z`、提示、补墙、撤销都不碰盘
  （`js/main.js` 的 `blockedWhilePaused`，页面上那句键位说明也写了这条），被拦下的那一下把理由
  写进 `#status-line`。穿得过锁的只有解暂停那两颗键、「换一局」（新局一定在走表）与 `Esc`（回选档，
  不改这盘的盘面）。为什么必须连盘一起锁：纪录的比法是**提示 → 步数 → 用时**
  （`js/store.js:136-141`），只停表不把盘子冻住，就是拿暂停去喂那把尺的最后一格——想完整盘再按继续，
  交上去的用时里少掉那几秒。`pause` 场（`tools/scenarios.js:1332` 起，51 条）把这两件事各量成断言：
  表那侧钉 `frozen === 0` 与 `frozenP === 0`（恰好 0，不是"变慢了"），盘那侧把上面每一个入口在暂停中
  按一遍、比较前后两次的整张墨水表，再用恢复后的同一批入口做对照组（锁盘不许是全场死）。
- 提示走的是**出题时那条铅笔序列**（`js/ui/game.js:353-373`）：它只说"这一条边必须是墙 / 必须
  打通"，并点名是 R1–R7 里哪一条给的结论，不替你收尾整盘（`index.html:159-160`）。你自己已经
  画反了的时候，提示拒绝落子、也不计费（`js/ui/game.js:355-358` 的 `charged: false`）。
- 侧栏读数（块/记号、未定格、墙、打通、步数、提示、说不通，`index.html:96-103`）全部由引擎现算，
  不是界面自己数格子。
- 存档只有一份、一个键 `tatamibari.save.v1`（`js/store.js:17`）：接着上次那盘继续，或者「清空
  本地存档」从头来。纪录的比法是**先比没求助的提示次数，再比步数，最后比用时**
  （`js/store.js:136-141`），页面上那句说明是同一口径（`index.html:73`）。

## 这四条承诺，每一条怎么变成一条会红的命令

| 承诺 | 怎么检查 |
|---|---|
| **零猜测**：出货的每一盘都能用那七条从空盘推到底，一次都不许回头猜 | 出货谓词里「铅笔推得完」是一个 AND 分支（`js/engine/generate.js:3-16`）；`tools/balance.mjs` 的「承诺一」那一段拿**出货的盘**重跑一遍求解器，五档各 24/24 局推完、全程不回溯，红即 `exit 1` |
| **唯一解由第二套互不信任的穷举器逐盘复核**，不是"没找到第二个" | 出货走 `countAnchored({limitSolutions: 2})`（锚定性质，`js/engine/generate.js:113`）；`countCover` 不假设锚定性质（每个记号枚举它能落在的任何位置、MRV 分支、BigInt 位掩码，`js/engine/counter.js:179`）。「承诺二之续」对**本轮出货的每一张盘**跑两套并比**解集**（矩形四角 + 它吞掉的记号 id），没数完＝没复核，直接判红（`tools/balance.mjs:264-296`）。本轮读数：五档各 24/24 逐块一致，解数分歧 0、解集分歧 0、没数完 0 |
| **提示只给"下一步可证的事实"**，并且说清凭哪条规则 | 提示的唯一来源就是出题那条铅笔序列，`R1–R7` 每一步都在**所有**合法分块上成立（`js/engine/pencil.js:8-12`）；`tools/pencil-test.mjs` 的 C 节拿真值分块逐条审计这条通道，而不是只测自洽（206 条里的主体）。看盘时两条通道还给过一遍逐边一致：`js/ui/game.js:167-185`，浏览器里那句证词在 `tools/scenarios.js:976` 断言 |

## 这个仓**不承诺**什么

- **不承诺「唯一解 ⟹ 铅笔推得完」**。R1–R7 七条不完备，反方向不成立：有些唯一解的盘这里就是
  推不完——那正是生成器要丢掉的东西，不是漏网的答案。本轮拒收计数把这件事说了两遍：入门
  154 次「铅笔推不完」、简单 530、中等 1886、困难 7808、大师 45693。
- **不承诺 6×6 以上有题可玩**。`UNSHIPPABLE` 里那三个尺寸是本轮量的结论，不是猜测：7×7 在结构
  下限之内 6000 抽 0 张、30000 抽只出 1 张（≈17 s/盘）；8×8 是 0/30000；10×10 是 0/30000
  （放宽到 `[9块,最大块<=34]` 也是 0/30000）。这一段 `balance` 每轮重新量，**哪天抽得出盘而
  `TIERS[]` 没加档，那一步就红**——这条结论不许变成传说。要开大档得先加推理规则，不是先加档名。
- **不承诺出题的墙钟预算**。进 stdout 闸的墙钟是**复核**那一段的尾巴：p95 ≤ `budgetMs` × 2
  （`tools/balance.mjs:61` 的 `HEADROOM`，判定与打印在 `tools/balance.mjs:240-262`）。搜索那一段的墙钟只作读数，
  因为它根本不是单峰的：同一份代码、同一串 seed（`balance|<档>|<局>`）本机连跑三次，入门档的每局
  墙钟读出来是 3.9 / 4.4 / 4.9 ms——除了时间，那一节的每一列都逐字复现。拿"中位×2"去卡一个抽数
  分布的尾巴会一绿一红，所以这里宁可在界面上挂"正在出题"的遮罩（`js/main.js:269-270`）也不写一个
  假的毫秒承诺。
- **不承诺线索最少**。「极小性」那一段是每档抽 4 局、逐个记号**试删**，看删完是否还满足出货三判据；
  本轮 186/186 次试删全部出局（挡下原因：推不完 184、结构不过 2）。这说的是"抽样里没有冗余记号"，
  不是"这张盘的记号数已到极小"。生成器那头的 `pruneMarkers` 同样是贪心删。
- **不承诺每格分单调**。五档的分数分布由尺寸、记号数与规则出场共同决定，原始分递增里有尺寸贡献；
  阶梯那句判的是**中位严格递增**，不是每格成本。
- **没有烘焙题本**。仓里没有 `js/data/`，也没有 `tools/bake.mjs`：每一局都是现场出的题，出题时
  就跑一遍铅笔推演与穷举唯一性证明（`index.html:113` 那句说明是这件事的玩家可见面）。
- **有代码、但浏览器闸没断言过的分支**：`integrity` 不为 null 时那句"引擎没能从空盘把这一盘推到底
  ——本盘不出"（`js/ui/game.js:147-149`，界面在 `js/main.js:308-309` 把它打到菜单状态行）。
  出货盘必然推得完，正常玩法碰不到这句话；闸断言的是它的**反面**（`tools/scenarios.js:486`、
  `tools/scenarios.js:1176` 都钉 `integrity === null`），那句拒绝文案长什么样、渲染在哪，没有任何断言读过。
- **只在 headless Chrome 里绿过**（本机 macOS 与 CI 的 ubuntu-24.04 两种环境，Safari、Firefox、真机
  iOS/Android、低配设备未经验证）。`bash tools/verify.sh` 在本机跑 root 形态与带
  `/z-biz-game-tatamibari-cos/` 前缀的两种 URL（各 11 个场景、各 387 条、0 failed；2026-10-04 那一跑
  root 16 s · prefix 17 s）；CI 在同一条命令上两条 job 都报 success（run #13，SHA `dfe0888`）——
  runner 自己打印的条数住在 Actions 日志里，读它要 `actions:read`，本机这把 PAT 会 403，所以这里只
  记它的红绿、不抄它的数。已部署站点那一种形态走 `BASE_URL=` 那条路（`tools/verify.sh` 的用法块
  `tools/verify.sh:8-12`）：同一天对着线上 `dfe0888` 跑是 **11 场景 387 条 / 0 failed / 23 s**、exit 0，`pause`
  那条交回 `fs 'entered'`（全屏腿在线上排得进去，不是只在 localhost 才绿）、`frozen 0`/`frozenP 0`/
  `jump 13`；发送的那 13 个文件（`index.html` + `css/` + `js/`，个数由 `git ls-tree -r dfe0888`
  现数）线上与本地逐文件 sha256 全相同——0 个不一致、0 个取不到，闸绿的是那份字节，不是本机侥幸能跑的
  那一份。部署工作流是无构建的文件拷贝（`.github/workflows/pages.yml`）。
- **无障碍只做了两件事**：`prefers-reduced-motion` 有一整套降级（`css/game.css:546`），画布有
  `role="img"` 与一句说明性的 `aria-label`（`index.html:108`）。键盘导航顺序、读屏播报、
  `aria-live` 的实际朗读内容都没有断言过——闸点的是画布像素与 DOM 文本。
- Electron 壳（`electron/main.cjs`）只有 `npm run check` 的 `node --check` 级检查，没有任何运行时
  断言。
- 文档对账那条腿只读**带路径**的引用。写成 `:1176` 这种"路径由上文继承"的续引它一条也看不见
  （DESIGN.md 里还有一批），`aria-label` 这类带连字符的名字也构不成锚点——被这条腿判绿的引用，
  不等于它的邻居也被判过。

## 难度是量出来的

分数 = Σ(`RULE_WEIGHT` × 该规则在这盘出手的次数) + 25 ×（铅笔重扫轮数 − 1）。权重表在
`js/engine/generate.js:89-97`（R1 记号互斥 1 · R2 窗口构型表 3 · R3 区域尺寸推理 5 · R4 定形封闭 7 ·

出货分数（本轮 `规则加权和 73 + 轮数项 25×2 = 123`，与出货分数一致）。

## 跑测试：七条命令各自证明什么

```

node tools/rule-test.mjs                          → 65 条：合法盘定义与它的两条独立读数
node tools/counter-test.mjs                       → 74 条：两套穷举互相对答案（含"数到 2 就停"的语义）
node tools/pencil-test.mjs                        → 206 条：A0 分层 + 底座对暴力 + 每条规则单独跑 + 真值逐条审计 + 强度差

SAMPLES=24 node tools/balance.mjs                 → 五档阶梯、两条承诺、极小性抽样、复解一致、UNSHIPPABLE 重量，退出码 0
```

`206` 是 2026-09-28 那一轮的条数，不是常数：A0 那节扫的是 `js/engine/` **目录本身**，多一个引擎
文件就多 3 条断言（`tools/pencil-test.mjs:206-215`）。`.github/workflows/ci.yml` 里写死了这组数字
当合同，改代码导致条数变化时必须一起改那里，并把新读数写回本节——把条数改小去迁就一次红，等于
让闸不再测它声称在测的东西。

文档对账那条腿管的是本文自己的数字：引用指出去，文件必须在盘上、行号不许越界，而且**贴着引用写在
反引号里的那个名字必须真的出现在被指的那几行里**——只查越界抓不住"落在隔壁元素上"的漂移，
`index.html:102` 那一条至今在界内却指错了地方（画布在 108 行）。它另有三把自检：四把假引用
（文件不存在 / 越界 / 锚点漂 / 行数错）必须一把不落全被抓到、一份真引用必须判绿、把日课那条
`daily:` 引用挪回它本轮之前的 227 行必须为它变红；而它数到的引用条数写进了本节，写完就由它自己
对账（抄错一格就红，把数字删掉同样算红）。

浏览器闸的 11 个场景各自咬住一块（`tools/verify.sh:39` 的清单，`tools/scenarios.js:1569` 注册）：
`first` 78 条（启动、选档页、DOM 面、空盘像素）、`play` 50（真指针的一局）、`undo` 35、`hint` 17、

## 技术形态

- 零运行时依赖的 ES 模块静态站：`index.html` + `css/` + `js/`，没有构建步骤，Pages 的部署就是
  文件拷贝（`.github/workflows/pages.yml`）。
- 目录：`js/engine/`（规则、穷举、铅笔、出题、验证）、`js/ui/game.js`（状态机与撤销栈）、
  `js/render/board.js`（画布）、`js/main.js`（接线）、`js/store.js`（localStorage）、

## 上线的到底是哪一批文件

这个仓没有打包器：站点=一次文件拷贝。以前「拷哪些」写在 `pages.yml` 的 `run:` 里（手抄的几行
`cp`）。本地 `index.html` 直读仓库根，永远自洽；线上却按那份清单拷，于是页面后来引用的
`manifest.webmanifest`、`sw.js`、`icons/*` 可能一个都没上去——线上 404，而仓里的引擎测试与
真浏览器闸全绿，因为它们跑的都是仓库根，没有任何一步在「按清单拷」的那个环境下加载过页面。

现在清单只有一份，住在 `tools/assemble-site.sh`：CI 调它拷 `_site`，本地闸调它拷临时目录，
然后**对拷出来的产物**提要求（`tools/deploy-set.mjs`）：

- **W 清单与页面同源**：`pages.yml` 里必须真有 `run: bash tools/assemble-site.sh <dir>` 这一行，
  `ci.yml` 里必须真有 `run: node tools/deploy-set.mjs`。认的是调用那一行，不是文件里出现过这个
  路径——注释里本来就会写它，只 grep 字符串会被一句散文喂绿。
- **R 引用可达**：引用不靠手打名单。从 `index.html` 的 `href/src` 出发，凡解析出来是 `.js`/`.css`
  的就把那一站也扫一遍（CSS 的 `url()`、JS 去掉注释后的 `'./…'` 字面量、`new URL(x, base)` 的两种
  基、`navigator.serviceWorker.register`、`scope`），`manifest` 的 icons/screenshots/shortcuts 各自
  的 `src` 也算引用。取径上读不到的那一站本身就是红（读不到＝这一站根本没扫）。每条引用都必须在
  产物里且非 0 字节；绝对路径单列一条红，因为 Pages 挂在 `/<repo>/` 前缀下会跳出去。
- **P 位图不许说谎**：`manifest` 声明的 `sizes` 必须等于 PNG IHDR 的真实宽高——文件图标读文件头，
  内联成 base64 的图标先解码再读同一段。后一条不是可选项：图标可能住在清单里而不是盘上的 `.png`
  （有的仓另有一条"零二进制文件"的承诺，那条只约束"有没有 .png 这个文件"）；如果 P 段只筛文件名，
  声明写 512 而真图 192 就一路放行。
- **钉住两个数**：R 段实际检查的路径条数（`35`）与这一次跑的断言条数（`53`），两个数
  都钉在 `tools/deploy-set.mjs` 顶部的那对常量里。没改页面却掉了，说明解析断了；删掉一张图标会同时
  少一条 R10 与那张的 P1/P2，所以两个数一起钉，断言条数能漂就是闸在缩水的信号。这一节故意只写数值、
  不写那对常量的名字，也不写别仓文档闸的编号：有的仓的文档闸会拿"文档里出现过的同名标识号"回数它
  自己的条数，还有的会把文档里点到的每个组编号逐个核对"这一轮真的发过"——两道闸共用一个名字，
  或者在本仓的文档里出现一个本仓没有的组编号，打红的都是不相干的那一边。

`tools/deploy-set-selftest.mjs` 是这两颗钉的阳性证明：它把仓库复制到临时目录，照着每一类断言
各下一刀（X1 清单不收位图目录 / X2 模块边改名 / X3 CSS 写绝对路径 / X4 `start_url` 绝对 /
X5 删光 >=512 图标 / X6 少一个必填字段 / X7 声明尺寸与真图不符 / X8 workflow 不调脚本 /
X9 CI 不跑闸 / X10 是阴性对照——往入口 JS 追加一行只写在注释里的假路径，闸必须仍然绿、条数仍然
`35`、断言仍然 `53`；X11 og:image 退回相对路径 / X12 og:image 的前缀指向别的 slug /
X13 内联位图谎报尺寸——只在有靶子时下：X11/X12 要页面上那句 og:image，X13 要清单里真有一段 base64
图标，没有就打印 SKIP；反过来 X1 没有位图目录可砍时改砍 css，P 段一位都不核时台架直接报靶子不够），
要求每一刀都让闸**点名**变红。靶子从 `DEPLOY_SET_DUMP=1`
的出处表现挑（取径真的会读的那支 JS / 那一张 CSS，不写死某一个仓的入口名），所以页面改了、仓与仓
不同，台架跟着走。

`node tools/deploy-set.mjs` 与 `node tools/deploy-set-selftest.mjs` 就是 CI 跑的那两条命令本身
（package.json 里的 `deploy-set` / `deploy-set:selftest` 只是同一支脚本的 npm 入口）；本仓的整闸在 `tools/verify.sh` 的 `=== deploy-set ===` 那一段也各跑一次。它们红的时候并进本仓那条出口的退出码——这一条是这么证的：
把 ci.yml 里那行 `run: node tools/deploy-set.mjs` 砍掉，本仓整闸必须点名红且退出码非 0。
所以「本地全绿、线上 404 自己的 manifest / sw.js / 图标」这一类坏法在本地就会红。

# 畳バリ Tatamibari · 切块与墙的推理

在 `W×H` 的盘上，墙把格子切成若干块。记号写着它所在那一块的**形状**：`-` 要宽大于高、`|` 要高于宽、
`+` 要正方形；每一块恰好一个记号，每一块都得是长方形，而且任何一个格点上不许四块共角。这里出货的
每一盘都只有一个答案，也每一盘都能用七条局部推理（R1–R7）从空盘一路推到底——一次都不许靠猜。

本文里的数字只有两类来源：仓里读得到的代码（写成 `文件:行号`），和 2026-09-28 那一轮全绿跑出来的
读数。跑的命令是 `npm run check`、`npm test`（三套 65 / 74 / 206 条）、`SAMPLES=24 node
tools/balance.mjs`、`bash tools/verify.sh`，环境 Node v26.8.1 / macOS 26.6.2 / Apple M5 Pro
15 核。引擎断言与 `npm run check` 是当场重跑的（65 / 74 / 206 三条读数与上面同一轮）；难度分位表取
06:09 那一跑（之前同代码还连跑过两次，只有墙钟列在动），浏览器门禁取 06:14 那一跑，逐条列在下面。

**代码 > 本文档**：本文与 `js/`、`tools/` 冲突时，以代码和它跑出来的输出为准。

## 规则（玩家视角）

菜单里那五条就是规则本体（`index.html:26-30`），而且每一条都对得上引擎里的一个谓词
（`index.html:32-36` 把对应关系写在页面上）：

1. **`-` 的块宽 > 高**、**`|` 的块高 > 宽**、**`+` 的块是正方形**——记号字符与方向约束是
   `js/engine/counter.js` 的 `MARKER_CHAR` / `aspectOk`。
2. **每块恰好一个记号**，多一个少一个都算错。
3. **每一块都是长方形**，块与块之间用墙分开。
4. **任何一个格点上不能四块共角**（十字路口不许凑齐四家）——`js/engine/rules.js` 的
   `pointWindmill` / `windmillPoints`。

- 玩家画的不是格子，是**边**。每条内部边三态：未定 / 墙 / 同块（`js/engine/pencil.js:55`）。
  「同块」也是人能说出口的结论（"这格只能并进那块 `+` 的正方形"），所以两条通道都留着这一态。
- 判胜不另起口径：赢 = 边全定完 ∧ 每块确实是长方形 ∧ `invalidReason` 说这一盘合法
  （`js/ui/game.js:234`，它调 `js/engine/validate.js:40`）。而「什么算合法盘」在本仓**只有一份
  定义**，页面、生成器、三套测试台问的都是它——合法定义写第二遍，两个台架就会各自把 bug 写成期望
  （`js/engine/validate.js:14`、`tools/reference.mjs:3-9`）。

## 怎么玩

- 五档：入门 4×4、简单 4×5、中等 5×5、困难 5×6、大师 6×6（`js/engine/generate.js:299-320`）。
  **6×6 之上本轮出不起货**，理由与抽数写在 `js/engine/generate.js:329-345` 的 `UNSHIPPABLE` 里，
  `npm run balance` 每轮重新量一遍并打印数字。
- 也可以指定 seed（同一个 seed 同一张盘），或按日课开「全世界同一盘」：日课的 seed 串是
  `daily:<本地日期>:<档>`（`js/main.js:227`、日期键在 `:93-99`，用本地日期不套 UTC）。
  「换一局」那颗按钮**不是**日期函数（`js/main.js:101-102` 用 `Date.now()` 与 `Math.random()`
  现造 seed）——界面不许在你说"换一局"的时候其实给你端回今天那盘。
- 落子：点一下一条边界，按住拖是一笔连画，从自己已经画下的线上起笔就是擦掉；`1` 画墙、`2` 打通、
  `3` 擦、`H` 提示、`G` 补一眼墙（免费）、`Z` 撤销、`N` 换一局（`index.html:147-150`）。
  一笔算一条撤销记录，不是每条边一条。
- 提示走的是**出题时那条铅笔序列**（`js/ui/game.js:353-373`）：它只说"这一条边必须是墙 / 必须
  打通"，并点名是 R1–R7 里哪一条给的结论，不替你收尾整盘（`index.html:151-154`）。你自己已经
  画反了的时候，提示拒绝落子、也不计费（`js/ui/game.js:355-358` 的 `charged: false`）。
- 侧栏读数（块/记号、未定格、墙、打通、步数、提示、说不通，`index.html:88-99`）全部由引擎现算，
  不是界面自己数格子。
- 存档只有一份、一个键 `tatamibari.save.v1`（`js/store.js:17`）：接着上次那盘继续，或者「清空
  本地存档」从头来。纪录的比法是**先比没求助的提示次数，再比步数，最后比用时**
  （`js/store.js:136-141`），页面上那句说明是同一口径（`index.html:68`）。

## 这四条承诺，每一条怎么变成一条会红的命令

| 承诺 | 怎么检查 |
|---|---|
| **零猜测**：出货的每一盘都能用那七条从空盘推到底，一次都不许回头猜 | 出货谓词里「铅笔推得完」是一个 AND 分支（`js/engine/generate.js:3-16`）；`tools/balance.mjs` 的「承诺一」那一段拿**出货的盘**重跑一遍求解器，五档各 24/24 局推完、全程不回溯，红即 `exit 1` |
| **唯一解由第二套互不信任的穷举器逐盘复核**，不是"没找到第二个" | 出货走 `countAnchored({limitSolutions: 2})`（锚定性质，`js/engine/generate.js:113`）；`countCover` 不假设锚定性质（每个记号枚举它能落在的任何位置、MRV 分支、BigInt 位掩码，`js/engine/counter.js:179`）。「承诺二之续」对**本轮出货的每一张盘**跑两套并比**解集**（矩形四角 + 它吞掉的记号 id），没数完＝没复核，直接判红（`tools/balance.mjs:264-296`）。本轮读数：五档各 24/24 逐块一致，解数分歧 0、解集分歧 0、没数完 0 |
| **提示只给"下一步可证的事实"**，并且说清凭哪条规则 | 提示的唯一来源就是出题那条铅笔序列，`R1–R7` 每一步都在**所有**合法分块上成立（`js/engine/pencil.js:8-12`）；`tools/pencil-test.mjs` 的 C 节拿真值分块逐条审计这条通道，而不是只测自洽（206 条里的主体）。看盘时两条通道还给过一遍逐边一致：`js/ui/game.js:167-185`，浏览器里那句证词在 `tools/scenarios.js:976` 断言 |
| **难度是量出来的**：`TIERS[].band` 是实测区间，不是作者的感觉 | `SAMPLES=24 node tools/balance.mjs` 的三道闸：五档全出货、入带率 100% 且中位在带内、中位严格递增（本轮 97 < 146 < 181 < 211 < 262），外加「分数口径自证」拿出货盘按 `RULE_WEIGHT` 手算必须等于出货分数（`tools/balance.mjs:435-436`）。band 一旦说谎，这一步就会红 |

## 这个仓**不承诺**什么

- **不承诺「唯一解 ⟹ 铅笔推得完」**。R1–R7 七条不完备，反方向不成立：有些唯一解的盘这里就是
  推不完——那正是生成器要丢掉的东西，不是漏网的答案。本轮拒收计数把这件事说了两遍：入门
  154 次「铅笔推不完」、简单 530、中等 1886、困难 7808、大师 45693。
- **不承诺 6×6 以上有题可玩**。`UNSHIPPABLE` 里那三个尺寸是本轮量的结论，不是猜测：7×7 在结构
  下限之内 6000 抽 0 张、30000 抽只出 1 张（≈17 s/盘）；8×8 是 0/30000；10×10 是 0/30000
  （放宽到 `[9块,最大块<=34]` 也是 0/30000）。这一段 `balance` 每轮重新量，**哪天抽得出盘而
  `TIERS[]` 没加档，那一步就红**——这条结论不许变成传说。要开大档得先加推理规则，不是先加档名。
- **不承诺出题的墙钟预算**。进 stdout 闸的墙钟是**复核**那一段的尾巴：p95 ≤ `budgetMs` × 2
  （`tools/balance.mjs:61` 的 `HEADROOM`，判定与打印在 `:240-262`）。搜索那一段的墙钟只作读数，
  因为它根本不是单峰的：同一份代码、同一串 seed（`balance|<档>|<局>`）本机连跑三次，入门档的每局
  墙钟读出来是 3.9 / 4.4 / 4.9 ms——除了时间，那一节的每一列都逐字复现。拿"中位×2"去卡一个抽数
  分布的尾巴会一绿一红，所以这里宁可在界面上挂"正在出题"的遮罩（`js/main.js:231-233`）也不写一个
  假的毫秒承诺。
- **不承诺线索最少**。「极小性」那一段是每档抽 4 局、逐个记号**试删**，看删完是否还满足出货三判据；
  本轮 186/186 次试删全部出局（挡下原因：推不完 184、结构不过 2）。这说的是"抽样里没有冗余记号"，
  不是"这张盘的记号数已到极小"。生成器那头的 `pruneMarkers` 同样是贪心删。
- **不承诺每格分单调**。五档的分数分布由尺寸、记号数与规则出场共同决定，原始分递增里有尺寸贡献；
  阶梯那句判的是**中位严格递增**，不是每格成本。
- **没有烘焙题本**。仓里没有 `js/data/`，也没有 `tools/bake.mjs`：每一局都是现场出的题，出题时
  就跑一遍铅笔推演与穷举唯一性证明（`index.html:107` 那句说明是这件事的玩家可见面）。
- **有代码、但浏览器闸没断言过的分支**：`integrity` 不为 null 时那句"引擎没能从空盘把这一盘推到底
  ——本盘不出"（`js/ui/game.js:147-149`，界面在 `js/main.js:270-271` 把它打到菜单状态行）。
  出货盘必然推得完，正常玩法碰不到这句话；闸断言的是它的**反面**（`tools/scenarios.js:486`、
  `:1176` 都钉 `integrity === null`），那句拒绝文案长什么样、渲染在哪，没有任何断言读过。
- **只在本地 headless Chrome 里绿过**。Safari、Firefox、真机 iOS/Android、低配设备未经验证。
  `bash tools/verify.sh` 跑的是本机 root 形态与本机带 `/z-biz-game-tatamibari-cos/` 前缀的两种
  URL（两种形态各 10 个场景、各 336 条、0 failed；06:14 那一跑 root 10 s · prefix 9 s · 整轮
  21.7 秒）。已部署站点那一种形态走
  `BASE_URL=` 那条路（`tools/verify.sh` 的用法块 `:8-12`），push 之后复跑，跑过之后数字才会
  出现在这里。部署工作流是无构建的文件拷贝（`.github/workflows/pages.yml`）。
- **无障碍只做了两件事**：`prefers-reduced-motion` 有一整套降级（`css/game.css:546`），画布有
  `role="img"` 与一句说明性的 `aria-label`（`index.html:102`）。键盘导航顺序、读屏播报、
  `aria-live` 的实际朗读内容都没有断言过——闸点的是画布像素与 DOM 文本。
- Electron 壳（`electron/main.cjs`）只有 `npm run check` 的 `node --check` 级检查，没有任何运行时
  断言。

## 难度是量出来的

分数 = Σ(`RULE_WEIGHT` × 该规则在这盘出手的次数) + 25 ×（铅笔重扫轮数 − 1）。权重表在
`js/engine/generate.js:89-97`（R1 记号互斥 1 · R2 窗口构型表 3 · R3 区域尺寸推理 5 · R4 定形封闭 7 ·
R5 记号可达 2 · R6 候选形状收敛 4 · R7 孤岛记号数 1），轮数项的 25 在 `:99`，累加在 `:144`。
这条口径不是解释性的：`balance` 的「分数口径自证」拿出货盘按同一张权重表手算一遍，必须逐局等于
出货分数（本轮 `规则加权和 73 + 轮数项 25×2 = 123`，与出货分数一致）。

## 跑测试：六条命令各自证明什么

```
npm run check                                     → 每个源文件 node --check 过，打印 OK
node tools/rule-test.mjs                          → 65 条：合法盘定义与它的两条独立读数
node tools/counter-test.mjs                       → 74 条：两套穷举互相对答案（含"数到 2 就停"的语义）
node tools/pencil-test.mjs                        → 206 条：A0 分层 + 底座对暴力 + 每条规则单独跑 + 真值逐条审计 + 强度差
SAMPLES=24 node tools/balance.mjs                 → 五档阶梯、两条承诺、极小性抽样、复解一致、UNSHIPPABLE 重量，退出码 0
bash tools/verify.sh                              → node 夹具 3/3 + 两种 URL 形态各 10 个场景 · 336 checks · 0 failed（root 10 s · prefix 9 s，整轮 21.7 s）
```

`206` 是 2026-09-28 那一轮的条数，不是常数：A0 那节扫的是 `js/engine/` **目录本身**，多一个引擎
文件就多 3 条断言（`tools/pencil-test.mjs:206-215`）。`.github/workflows/ci.yml` 里写死了这组数字
当合同，改代码导致条数变化时必须一起改那里，并把新读数写回本节——把条数改小去迁就一次红，等于
让闸不再测它声称在测的东西。

浏览器闸的 10 个场景各自咬住一块（`tools/verify.sh:39` 的清单，`tools/scenarios.js:1324` 注册）：
`first` 78 条（启动、选档页、DOM 面、空盘像素）、`play` 50（真指针的一局）、`undo` 35、`hint` 17、
`clash` 21（画反了当场被证伪，且提示拒答不计费）、`win` 51（遮罩、证词行、整盘墙改色）、
`save` 29 与 `resume` 31（**跨刷新**的一对：存档的 RLE 与真指针画出来的墨水必须同源）、
`layout` 12、`narrow` 12（真 390×844 视口，不是改 `max-width`）。

## 技术形态

- 零运行时依赖的 ES 模块静态站：`index.html` + `css/` + `js/`，没有构建步骤，Pages 的部署就是
  文件拷贝（`.github/workflows/pages.yml`）。
- 目录：`js/engine/`（规则、穷举、铅笔、出题、验证）、`js/ui/game.js`（状态机与撤销栈）、
  `js/render/board.js`（画布）、`js/main.js`（接线）、`js/store.js`（localStorage）、
  `tools/`（三套引擎门禁、难度量测台、台架参照件、浏览器闸）。
- `js/` 永远不许 import `tools/`：CI 里有一条裸 grep 钉它（`.github/workflows/ci.yml` 的
  「js/ never imports tools/」那一步），A0 那节再从引擎侧钉一遍。
- 本地服务器 `server.cjs`（`npm run dev`，端口 5316）只为开发；前缀形态用它自己的软链目录 +
  `python3 -m http.server` 复现（`tools/verify.sh:353-355`）。
